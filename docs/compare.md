# Compared with other tools

Use this page to pick a tool by the job you want done and to see how `pbx` compares with FreePBX's own tools,
Frogman and asterisk-ai-call-notes. The comparison itself lives on wirecat.dev, because it changes when the other tools
change, not when `pbx` is released.

Read the comparison: [`pbx` compared with other tools](https://wirecat.dev/en/docs/pbx/compare).
